Laundry Services – Responsive Landing Page
📌 Project Overview

This project is a responsive Laundry Services landing page built using HTML5 and CSS3.

The webpage promotes professional laundry services, allowing users to explore the service through a clean and simple user interface.

It includes a navigation bar, a hero section with service information, a call-to-action button, and a laundry image.

🚀 Features
Responsive navigation bar.
Attractive hero section.
Highlighted heading text.
Laundry service description.
Call-to-action button.
Laundry image integration.
Responsive layout for desktop, tablet, and mobile devices.
CSS Flexbox for layout management.
CSS media queries for responsiveness.
🛠️ Technologies Used
HTML5 – Structure of the webpage.
CSS3 – Styling and responsive design.
Flexbox – Layout alignment and positioning.
Media Queries – Responsive design for different screen sizes.
📱 Responsive Breakpoints
Device	Screen Width
Desktop	Above 768px
Tablet	481px – 768px
Mobile	321px – 480px
Small Mobile	320px and below

💻 How to Run the Project
Download or clone this repository.
Open the project folder in VS Code.
Make sure index.html, style.css, and Laundry.png are in the correct locations.
Open index.html in your browser.
Alternatively, use the Live Server extension in VS Code.
